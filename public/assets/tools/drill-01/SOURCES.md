# Cordless drill visual shell

- Source: [Poly Haven Drill 01](https://polyhaven.com/a/Drill_01), by Fernando Quinn.
- License: [CC0](https://polyhaven.com/license).
- Variant: official 1K glTF, binary buffer, diffuse, normal (OpenGL), and packed material JPG files; retained without geometric or texture edits.
- Runtime alignment: the imported shell is rotated and translated around the game's existing grip, trigger and masonry-bit anchors. The gameplay anchors and rotating bit remain authored in `src/player/ReferenceToolModels.ts`.
- This is a visual shell. It is not a replacement for collision, tool reach, or hand animation.
