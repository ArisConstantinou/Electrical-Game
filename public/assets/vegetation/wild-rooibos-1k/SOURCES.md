# Scanned dry field shrub

Source: [Poly Haven Wild Rooibos Bush](https://polyhaven.com/a/wild_rooibos_bush),
by James Ray Cock (model) and Jenelle van Heerden (photography), CC0.
Downloaded 2026-09-24 from the [Poly Haven files API](https://api.polyhaven.com/files/wild_rooibos_bush).

The package contains the original 1K glTF, its binary geometry, three 1K JPG
material maps, and the matching 1K JPG alpha map. The files are unmodified;
their MD5 values match those published by the files API. The runtime instantiates
the 2,684-triangle `wild_rooibos_bush_d` sample 115 times, using its photographed
clay-brown twigs and foliage with a cutout alpha map. Its source model has five
distinct samples; this field uses the compact `d` sample to keep mobile cost
reasonable. The older field shrub remains a load-failure fallback.

This is dry-site visual vegetation. It adds no gameplay collision and remains
inside the existing Studio asset pivot for the field shrubs.
