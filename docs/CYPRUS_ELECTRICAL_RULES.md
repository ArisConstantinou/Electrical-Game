# Cyprus / Company First-Fix Rules

This file records the supplied field workflow and company practice for game continuity; it is not a substitute for statutory design or inspection.

## Data-driven dimensions and heights

- 1G recessed box reference: 74 × 74 × 37 mm.
- 2G recessed box reference: 134 × 74 × 37 mm.
- Socket box bottom edge: 300 mm above finished floor.
- Light-switch box bottom edge: 1200 mm above finished floor.
- Main conduit in this mission: 20 mm rigid white PVC.
- Company mix reference: about 90% 20 mm; 40/50 mm mainly for large/main-power feeds.

## Real work sequence

1. Mark.
2. Chase masonry.
3. Fit boxes.
4. Mortar / secure.
5. Level and set flush depth.
6. Install conduits.
7. First-fix inspection — this vertical slice stops here.
8. Builders plaster walls.
9. Electrician returns.
10. Cable pulling.
11. Second fix.
12. Distribution board.
13. Testing.

Rigid PVC is preferred, especially where routes descend to the floor. Corrugated conduit is useful for awkward routes or many bends, but is easier to crush on site. Mortar fills the complete chased area around a grouped installation, finishes flush with the box rims and never covers box interiors.

## Reserved future cable notes

Cable pulling is not implemented before plaster. Later work should record solid-core conductors mainly for switches and sockets, twin cable only where the route has suitable protection, and flexible cable mainly outdoors such as spike-light installations.
