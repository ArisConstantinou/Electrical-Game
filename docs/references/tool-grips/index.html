Οι φωτογραφίες καθοδηγούν τη λαβή. Η τελική πόζα πρέπει να ελεγχθεί πάνω στο δικό μας μοντέλο από όλες τις πλευρές.

Τι πρέπει να παραμένει σωστό στην κίνηση

01 / ΕπαφήΠαλάμη και δάχτυλα πάνω στις πραγματικές λαβές. Ο δείκτης κινείται μαζί με τη σκανδάλη.

02 / ΚαρπόςΗ στροφή της κάμερας δεν αλλάζει από μόνη της τη σχετική πόζα παλάμης–αντιβραχίου–εργαλείου.

03 / ΣώμαΏμος και αγκώνας προσαρμόζονται χωρίς αναστροφή, διείσδυση στο στήθος ή παραμόρφωση του mesh.

04 / ΑπόδειξηΊδια πόζα από έξι όψεις, μετά πλήρης κίνηση πάνω/κάτω/δεξιά/αριστερά, κοντά στον τοίχο και σε χρήση.
